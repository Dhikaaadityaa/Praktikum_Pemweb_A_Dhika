Informasi Sistem

Aplikasi ini digunakan untuk mengelola data mahasiswa, termasuk menampilkan daftar mahasiswa dan menambahkan mahasiswa baru.

Fungsi Sistem

Sistem ini memiliki beberapa fungsi utama:

  • Menampilkan daftar mahasiswa
  • Menambahkan mahasiswa baru
  • Mengedit data mahasiswa
  • Menghapus data mahasiswa

Fitur Sistem

Beberapa fitur yang tersedia dalam sistem ini antara lain:

  • Formulir input data mahasiswa
  • Tabel daftar mahasiswa
  • Pencarian mahasiswa berdasarkan nama atau NIM
  • Validasi data input untuk memastikan keakuratan informasi

Tentang Kami

Kami adalah tim pengembang yang berkomitmen untuk menyediakan sistem informasi yang efisien dan mudah digunakan untuk pengelolaan data mahasiswa.
